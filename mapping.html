Panduan & FAQ

Catatan penting

Ini BUKAN login/akses yang sungguhan -- cuma penyaring tampilan (siapa pun yang paham teknis tetap bisa lihat data toko lain kalau mau). Hasil dari halaman ini adalah 1 file user-mapping.json yang Anda upload MANUAL ke folder data/ di GitHub (timpa yang lama). Tidak ada akun/password yang benar-benar dibuat di server mana pun.

Buat file mapping dari Excel

Kolom: Username, Nama (opsional), Store Name (format "ID-NamaToko"), Scope Channel (opsional, info saja). 1 baris = 1 kombinasi Username+Toko, boleh banyak baris untuk Username yang sama. Isi "SEMUA" di kolom Store Name untuk akun yang boleh lihat semua toko.
