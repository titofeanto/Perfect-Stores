Catatan penting

Halaman ini hanya menyaring tampilan toko. Ini bukan login atau pembatasan akses, jadi siapa pun yang paham teknis tetap bisa melihat data toko lain. Hasilnya 1 file user-mapping.json yang Anda upload sendiri ke folder data/ di GitHub (timpa yang lama). Tidak ada akun atau password yang dibuat di server mana pun.

Buat file mapping dari Excel

Kolom: Username, Nama (opsional), Store Name (format "ID-NamaToko"), Scope Channel (opsional, info saja). 1 baris = 1 kombinasi Username+Toko, boleh banyak baris untuk Username yang sama. Isi "SEMUA" di kolom Store Name untuk akun yang boleh lihat semua toko.
